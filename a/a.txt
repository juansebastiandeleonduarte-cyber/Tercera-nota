# Estructura básica de HTML5

Un documento HTML5 está compuesto por varias etiquetas clave que establecen la estructura y el contenido de la página. Aquí tienes la estructura más básica:

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de la Página</title>
</head>
<body>
    <h1>¡Hola, mundo!</h1>
</body>
</html>
```

### Componentes principales de la estructura básica

1. **`<!DOCTYPE html>`**:
    - Este es un **declarativo** que le dice al navegador que el documento es de tipo HTML5.
    - No es una etiqueta HTML en sí, sino una instrucción que asegura que el navegador renderice la página correctamente.
    - En versiones anteriores de HTML, el DOCTYPE era más complicado, pero en HTML5 es simple y breve.
2. **`<html lang="es">`**:
    - Esta es la etiqueta raíz de todo el documento HTML. Todos los elementos de la página deben estar dentro de esta etiqueta.
    - El atributo `lang="es"` indica el lenguaje principal del contenido del documento (en este caso, español). Esto es importante para accesibilidad y SEO (Search Engine Optimization), ya que los navegadores y motores de búsqueda usan esta información para mejorar la interpretación del contenido.
3. **`<head>`**:
    - El elemento `<head>` contiene **información meta** (información sobre la página que no es visible para el usuario directamente, pero que es esencial para los navegadores y motores de búsqueda). Dentro del `<head>` van etiquetas como `<title>`, `<meta>`, y enlaces a hojas de estilo o scripts.
    
    ### Ejemplos de elementos dentro del `<head>`:
    
    - **`<meta charset="UTF-8">`**:
        - Establece la codificación de caracteres del documento. `UTF-8` es la codificación de caracteres más común y permite representar la mayoría de los caracteres de los idiomas del mundo.
    - **`<meta http-equiv="X-UA-Compatible" content="IE=edge">`**:
        - Asegura que Internet Explorer use su motor de renderizado más moderno. Aunque no es tan común actualmente, sigue siendo útil para compatibilidad.
        - Está dirigido únicamente a Internet Explorer para que utilice su motor de renderizado más moderno (**Edge**), cabe resaltar que este tag es **poco necesario** en lo proyectos web actuales.
    - **`<meta name="viewport" content="width=device-width, initial-scale=1.0">`**:
        - Esto es crucial para que las páginas web sean **responsivas**. Hace que la página se ajuste adecuadamente en diferentes dispositivos, especialmente móviles, estableciendo la escala inicial de la página.
    - **`<title>`**:
        - Define el título que aparecerá en la pestaña del navegador. Es un componente esencial para SEO y usabilidad, ya que los usuarios lo verán cuando tengan varias pestañas abiertas.
4. **`<body>`**:
    - El contenido visible de la página va dentro del elemento `<body>`. Todo lo que el usuario verá (texto, imágenes, videos, formularios, etc.) se define dentro de esta etiqueta.
    
    ### Ejemplo de elementos dentro del `<body>`:
    
    - **`<h1>`**: Este es un encabezado de nivel 1, y en este ejemplo muestra el texto "¡Hola, mundo!". Los encabezados jerárquicos (`<h1>` a `<h6>`) ayudan a estructurar el contenido y son importantes tanto para la accesibilidad como para el SEO.
5. **Cierre de las etiquetas**:
    - Cada etiqueta debe tener su cierre correspondiente para asegurar que el documento esté bien estructurado. En el ejemplo, la etiqueta `<html>` comienza y termina, lo mismo ocurre con `<head>` y `<body>`.

### Ejemplos adicionales de contenido dentro del `<body>`:

```html
<body>
    <header>
        <h1>Bienvenidos a mi sitio web</h1>
    </header>
    <main>
        <p>Este es el contenido principal de la página.</p>
        <a href="https://www.ejemplo.com">Ir a Ejemplo</a>
    </main>
    <footer>
        <p>Todos los derechos reservados &copy; 2024</p>
    </footer>
</body>
```

- **`<header>`, `<main>`, `<footer>`**: Estas son etiquetas semánticas introducidas en HTML5 que facilitan la comprensión del contenido por parte de los navegadores y motores de búsqueda. Cada una de ellas tiene un propósito específico:
    - **`<header>`**: Usado para el encabezado de la página o sección.
    - **`<main>`**: El contenido principal de la página.
    - **`<footer>`**: La sección de pie de página, que generalmente contiene información como derechos de autor o enlaces secundarios.

### Importancia de la semántica en HTML5

HTML5 introdujo varias etiquetas semánticas como `<article>`, `<section>`, `<aside>`, y `<nav>`, que permiten organizar el contenido de manera más clara y comprensible, no solo para los desarrolladores, sino también para los motores de búsqueda y dispositivos de asistencia (como lectores de pantalla). Estas etiquetas reemplazan a las más genéricas como `<div>` para dar un significado más preciso al contenido.

### Ejemplo de etiquetas semánticas:

```html
<body>
    <header>
        <h1>Mi Blog</h1>
    </header>

    <nav>
        <ul>
            <li><a href="#home">Inicio</a></li>
            <li><a href="#about">Sobre mí</a></li>
            <li><a href="#contact">Contacto</a></li>
        </ul>
    </nav>

    <section>
        <h2>Artículo Reciente</h2>
        <article>
            <h3>Título del artículo</h3>
            <p>Este es un artículo que habla sobre HTML5.</p>
        </article>
    </section>

    <aside>
        <h3>Noticias relacionadas</h3>
        <p>Aquí podrías colocar noticias o enlaces de interés.</p>
    </aside>

    <footer>
        <p>Todos los derechos reservados &copy; 2024</p>
    </footer>
</body>
```

### Resumen

- **`<!DOCTYPE html>`**: Define el documento como HTML5.
- **`<html>`**: Contiene todos los elementos de la página y define el lenguaje del documento con el atributo `lang`.
- **`<head>`**: Contiene metadatos esenciales, como la codificación de caracteres y la información para hacer el sitio responsivo.
- **`<body>`**: Contiene todo el contenido visible de la página.
- **Etiquetas semánticas**: Mejoran la organización del contenido, la accesibilidad y el SEO.

### Importancia de una estructura básica bien definida

Una estructura básica correcta en HTML5:

1. **Mejora la accesibilidad**: Los lectores de pantalla y otros dispositivos de asistencia pueden interpretar mejor el contenido si la semántica es clara.
2. **Optimiza el SEO**: Los motores de búsqueda comprenden mejor la relevancia del contenido.
3. **Asegura compatibilidad entre navegadores**: HTML5 es compatible con todos los navegadores modernos, y una estructura adecuada reduce problemas de visualización.
